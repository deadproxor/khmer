# PWA Кхмерский — статус проекта

## Стек

- Чистый HTML/CSS/JS — без фреймворков
- Service Worker для офлайн-режима
- localStorage для хранения прогресса
- Web App Manifest для установки на Android
- PHP (локальный сервер) для build-скрипта

## Файловая структура

```
/khmer/
├── index.html        — всё приложение (~90 КБ)
├── manifest.json     — PWA манифест
├── sw.js             — Service Worker
├── icons/            — иконки 8 размеров (72–512px) — не трогать, свои
└── build/
    └── build.php     — обновляет версию кэша в sw.js по md5 от index.html
```

## Деплой

- Локальный сервер: PHP, файлы лежат локально
- Ремоут: solead.software/khmer/
- Деплой: вручную
- Перед деплоем: открыть `localhost/khmer/build/build.php` — обновит `CACHE` в `sw.js`
- `build/` на ремоут не деплоить

## Словарь

- 446 слов, 19 категорий
- Поля: `id`, `k` (кхмерский), `l` (латинская транскрипция), `r` (русская транскрипция), `ru` (перевод), `cat` (категория)
- Сейчас словарь зашит в `index.html`
- **Следующий шаг:** вынести в отдельный файл `khmer_dict.js` — пользователь загрузит свою версию

## Что реализовано

### Режим карточек
- Флип через CSS-чекбокс (`<input type="checkbox">` + `<label>`) — без JS на самом флипе
- Обратный режим: кхмерский → русский и русский → кхмерский, переключается кнопкой
- SRS алгоритм SM-2: Трудно / Нормально / Легко
- За сессию: все просроченные + до 20 новых слов

### Режим квиза
- 4 варианта ответа
- Правильный — зелёный, неправильный — красный
- Ошибки идут в SRS как «Трудно»
- Переключение направления (кх→рус / рус→кх)

### Прогресс и статистика
- Шапка: стрик 🔥, счётчик «Знаю X / Y»
- Статистика: Знаю / Учу / Не начато
- График активности за 7 дней
- Прогресс-бар по каждой категории
- Экспорт / импорт прогресса (JSON)
- Сброс прогресса с подтверждением

### Фильтры
- 19 категорий, горизонтальный скролл
- Работают для обоих режимов

### Прочее
- Тёмная / светлая тема, кнопка в шапке, сохраняется в localStorage
- Haptic feedback (Vibration API)
- Автоверсионирование SW через `build.php`
